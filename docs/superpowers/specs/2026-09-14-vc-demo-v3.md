# VC Demo V3 Design

## Goal

Replace the current investor walkthrough with a production capture that explains
each visible action as it happens and finishes in no more than 120 seconds.

## Approved flow

The video follows synthetic citizen Aisyah from the public landing page through
guest access, sample intake, the live analysis state, and an explicit time jump
of about one minute. The completed evaluation then shows the result total,
reveals the top scheme's blurred **Why you qualify** explanation, expands its
official sources, and moves to **Strategy**.

From Strategy, the walkthrough opens Cik Lay as the compact side panel with the
recommendation already staged, expands it into the centre modal, types a
concrete application-and-documents question for Aisyah's top JKM match, and
waits for a substantive, relevant answer. It then closes Cik Lay, demonstrates
a what-if income change, and ends on the generated application packet.

## Presentation constraints

- Narration must describe the interface currently on screen.
- All page motion must use the existing constant-speed scrolling helper.
- Production warm-up must occur before recording because Render may cold-start.
- Chatterbox must clone the approved Columbina reference voice.
- Quicksand subtitles remain small and low; their black backing must use less
  vertical padding so adjacent rows do not overlap.
- The lofi music bed remains ducked beneath narration.
- The final MP4 must be 1920×1080 H.264/AAC and no longer than 120 seconds.
- The verified export replaces `~/Downloads/Layak-VC-Walkthrough.mp4`.
